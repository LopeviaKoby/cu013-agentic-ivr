# North Star Vision

A natural, intelligent, contextual and low-latency telephone IT-support conversational agent operating within the actual XCALLY / Cally Square media path.

## Core Pillars

1. **Natural Dialogue**: Callers speak freely without menu-driven constraints. The LLM understands multi-fact utterances, clarifications, and corrections in natural spoken Spanish.
2. **Deterministic Business Control**: Code verifies business rules, authorization, and protocol safety before any action is executed.
3. **Low Latency for Telephony**: End-to-end backend processing under 1.5 seconds to sustain natural voice pacing.
4. **Reliable Session Continuity**: Multi-turn dialogue context is safely preserved in Firestore across conversational turns.
